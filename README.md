EduGenie is an AI-powered learning companion that helps students learn anything, anytime using Google Gemini AI.

### ✨ Features
- 🤖 Ask any doubt - AI Tutor 24/7
- 📝 Summarize long notes, PDFs, YouTube videos
- 🧠 Generate Quiz, Flashcards, Mindmaps automatically
- 📚 Personalized Study Plan
- 🗣️ Simple Explanation like a friend

### 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript / React
- Backend: Python Flask
- AI: Google Gemini 1.5 Flash API
- Hosting: Vercel / Render

### ⚙️ How to Run

```bash
git clone https://github.com/bharathibharathi0743-ux/EduGenie-Gemini.git
cd EduGenie-Gemini
